# GUI 能力与集成约定

本文描述当前 GUI 的能力及维护边界。用户操作步骤见[用户手册](manual/manual_cn.md)，蒙版制作见其[附录 C](manual/manual_cn.md#附录-c遮罩文件制作说明)。界面入口为 `HoshinoWeaver desktop.py`。

## 工作流与动态参数面板

主界面通过工作流选择和模式选项确定计算流程；`PanelSchema` / `DynamicConfigPanel`根据配套 `.ui.yaml` 生成输入、参数及路由控件，输出设置由独立面板管理。显示声明和计算语义分别由 UI YAML 与 Meta YAML 定义，见[技术概览](README.md#gui-与工作流文件)及 [Meta YAML v2](meta_yaml_v2_spec.md)。

蒙版参数使用 `widget: mask_picker` 显式声明。它保留文件浏览和清空能力，增加编辑入口；不会因为参数名称为 `mask` 就自动改变普通文件控件。当前已用于星轨叠加、对齐叠加、星轨延时和延时降噪的相关蒙版参数。`visible_when` 只控制显示，不改变工作流参数的提交规则。

## 天空蒙版编辑能力

编辑器提供独立非模态窗口。每个主窗口维护一个编辑器，支持以下能力：

| 能力 | 当前行为 |
| --- | --- |
| 文件导入 | PNG/JPEG 转灰度，以灰度 ≥128 为天空；拒绝非不透明像素 |
| 文件保存 | 原子写入无损 PNG，像素为 0/255，白色表示天空、黑色表示地面 |
| 自动生成 | 调用分割服务，缓存阈值后的 bool 蒙版；重新生成 |
| 预览 | 原图、纯蒙版、彩色叠加；叠加透明度可调 |
| 编辑 | 天空/地面硬画笔、反相、撤销与重做；笔刷可按图像尺寸调整或固定屏幕大小 |
| 视图操作 | 滚轮缩放、右键或中键平移、适应窗口 |
| 工作流集成 | 保存文件与参数应用分开；参数入口支持“保存并应用” |

### 双入口与显式回填

预览区入口在具有蒙版控件的工作流中显示，打开独立编辑会话，只保存文件。蒙版参数旁的“编辑”入口打开同一窗口，加载该参数已有文件，并提供“保存并应用”。两个入口默认都使用打开时主界面当前展示图的快照。

普通保存只写文件；“保存并应用”在保存成功后回填原参数路径。`MaskTarget` 通过当前面板的绑定令牌检查目标身份，工作流切换或相关路由参数重建后失效；面板运行锁定期间也不接受回填。旧目标失效时仍可保存文件，不会回填新面板。

### 参考图和编辑会话

编辑会话持有参考图副本。主界面浏览其他图片不会自动替换正在编辑的底图；重新打开编辑器时采用当前展示图。同一参考图的草稿或同路径、同尺寸蒙版可沿用文档与历史，只更换参考底图。其他文档替换、重新生成或关闭若会丢失修改，会询问保存、放弃或取消。参考图和蒙版尺寸不符时拒绝载入并保留已有文档，不静默缩放。

### 主预览的序列蒙版

“保存并应用”成功后，该参数的蒙版用于当前工作流的主预览叠加。之后展示的同尺寸图片共享此叠加；不同尺寸不拉伸，显隐按钮置灰并说明原因。预览区顶部工具栏提供编辑入口和蒙版显隐按钮。普通保存不会首次启用序列预览。

## 生成任务与进度

GUI 编辑器为每次生成显式创建自己的 service scope。输入使用 GUI 的 uint8 参考图，通过 `services.segmentation.predict_sky()` 生成蒙版；模型接口、输入适配与推理算法见 [服务说明](services.md#skyseg-v2-天地分割)和 [模型部署元信息](model_metadata.md)。生成结束只保留 bool 蒙版。

| 阶段 | 进度显示 |
| --- | --- |
| 初始化 | 等待状态 |
| 全局定位 | 按尺度推进至 40% |
| 局部细化 | 按实际选中窗口数推进至 95%；零窗口直接进入融合 |
| 原尺寸融合 | 97% |
| 结果缓存 | 99%，缓存成功后到 100% |

这些比例是阶段分配，不是耗时或剩余时间估算。worker 事件经 Qt queued signal 转发到 GUI 线程；旧请求、已完成请求和取消后的迟到事件不会覆盖当前状态。生成期间锁定文档修改，主界面仍可浏览其他图片。取消会等待服务请求排空并释放资源；原生计算可能继续完成整个请求，不承诺即时停止。生成中关闭编辑器或主窗口，也会先取消并等待资源收尾。

## 模块与状态边界

| 模块 | 职责 |
| --- | --- |
| `ui/mask_document.py` | bool 文档、路径和修改状态、保存检查点、分块笔划历史 |
| `ui/mask_canvas.py` | Qt 图像及蒙版叠加、坐标变换、画笔输入和局部刷新 |
| `ui/mask_editor.py` | 文件操作、工具状态、生成任务、窗口生命周期、主预览集成 |
| `ui/mask_target.py` | 可撤销的参数回填目标 |
| `ui/widgets.py` / `ui/panel_builder.py` | 蒙版参数控件、绑定令牌及路由失效处理 |
| `ui/UILibs.py` / `ui/preview_toolbar.py` | 主预览蒙版叠加及显隐工具栏 |

Qt 图像和显示缓冲留在 GUI 层，不依赖计算库完成显示。
撤销按 128×128 像素块记录笔划变化，历史预算 64 MiB；至少保留最近一次操作。
